# FDE Projects · 开源实战项目入口

[10项项目目录](project-catalog.md)给出业务场景、技术架构、难度、代码状态、模拟数据与验收方式。Awesome-FDE维护统一索引，完整应用可由独立仓库维护。

目前可直接运行的是本仓库[离线交付练习](../cookbook/examples/README.md)；其余应用明确标注规划状态。公开的本体知识仓库提供方法参考，不自动等于可部署应用。

贡献新项目请使用[项目模板](project-template.md)，提交源码、部署说明、数据许可、实际测试记录与维护人。图书关联见[学习中心](../book/README.md)，生态入口见[社区](../community/README.md)。
