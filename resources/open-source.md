# 开源与可用源码项目

[技术图谱](frameworks.md)集中维护20个重点项目的官方仓库、文档、定位、场景、特征、许可与企业注意事项。MIT、Apache等与自定义/source-available条款分别标记，不将所有可见源码都称为OSI开源。

## 选型方法

1. 固定候选版本和部署方式，检查LICENSE及依赖/模型许可。
2. 用同一数据集测质量、延迟、资源与恢复能力。
3. 评估中国大陆访问条件、模型接入可用性、私有化资源和数据出域路径。
4. 记录迁移、导出、删除与替换成本，填写[选型矩阵](../toolkit/templates/technology-selection.md)。
