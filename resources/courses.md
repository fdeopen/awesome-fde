# 综合课程

选择课程时，以“能否产出真实项目证据”为标准，不以观看时长为标准。

- [FDE Guide](https://github.com/bingyue/fde-guide) — 从角色边界、客户发现到 RAG、Agent、评估、治理与商业交付的中文专栏。`中文` `免费` `核验：2026-09-07`
- [Hugging Face Learn](https://huggingface.co/learn) — LLM、Agent、上下文工程、强化学习等课程入口。`英文` `免费` `核验：2026-09-07`
- [Full Stack Deep Learning](https://fullstackdeeplearning.com/) — 从模型到产品与生产系统的工程课程。`英文` `免费` `核验：2026-09-07`
- [Made With ML](https://madewithml.com/) — 数据、训练、测试、部署与 MLOps 的实践课程。`英文` `免费` `核验：2026-09-07`
- [DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/) — LLM 应用、RAG、Agent 与评估的专题课程入口。`英文` `免费/付费` `核验：2026-09-07`

建议按 [四条学习路线](../learning-paths/) 选择课程，并为每个阶段留下代码、评估集、架构决策或复盘记录。
