## 如何使用

先选择与你的业务相关的案例，再阅读原文与[案例拆解](selected.md)。把值得验证的做法写入[机会卡](../templates/discovery/opportunity-card.md)，按[Playbook](../playbook/README.md)明确数据、负责人和验收条件。

本选集只展示公开案例与公开工程实践。原有 119 篇文章仍保留在[完整资料索引](catalog.md)，其中包含行业分析等其他阅读资料，不与精选案例数相加。
