# FDE Cases · 企业AI案例索引

本目录按来源与证据组织案例。119篇社区文章通过[分类目录](catalog.md)关联原文，仅保留标题、摘要和来源；不复制第三方全文。文章可能讨论多个企业，也可能是技术实践，不能按文章数计算已验证企业项目数。

## 四种资料类型

| 类型 | 使用方式 | 必须提供 |
| --- | --- | --- |
| 企业授权案例 | 可公开复盘特定项目 | 授权、脱敏、范围、基线与证据 |
| 公开案例/文章 | 阅读与方法参考 | 原始来源、日期、来源自述标识 |
| 参考实现 | 理解代码与部署 | 源码、版本、运行条件、已测边界 |
| 模拟教学案例 | 练习流程与验收 | 合成声明，不冒充客户结果 |
