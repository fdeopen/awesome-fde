# 金融案例

重点场景：研究助手、合规审查、理赔、风控支持、客服和运营知识流。

## 必须关注

- 受监管数据、模型风险、审计和记录保留
- 建议、决策与执行的边界，以及最终责任人
- 高风险错误、偏差、解释、申诉和人工复核
- 金额、频率、账户、工具权限和双重确认
- 外部披露、收益表述和独立验证边界

行业公开资料参阅[119篇来源索引](../catalog.md)，新案例使用[14项模板](../case-template.md)。这些阅读资料不等于本仓库独立验证的企业交付结果；完整练习参阅[模拟教学案例](../enterprise-services/synthetic-service-desk.md)。
