# 制造业案例

重点场景：设备运维、质量检测、工艺知识、生产日报、供应异常、排产辅助和现场服务。

## 必须关注

- IT/OT 网络隔离、PLC/MES/ERP 接口和现场安全
- 错误动作对设备、人员、产线和交付的影响
- 实时性、停机窗口、离线运行与人工接管
- 工艺版本、批次、设备、物料和责任人的可追溯性
- 效率提升是否转化为产能、质量、库存或交付结果
