# 6. 技术方案设计

## 阶段目标

形成满足约束的最小可运行闭环。

## 输入与输出

- 输入：优先场景、数据目录、非功能约束。
- 输出：ADR、系统卡、风险清单与报价边界。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

比较规则、检索、工作流与Agent；画数据流，评估许可、部署与退出成本。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

把平台演示能力当作企业控制能力；逐项验证。高风险动作设计人工确认与补偿。

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。继续到 [7. PoC原型验证](../poc-delivery/README.md)。
