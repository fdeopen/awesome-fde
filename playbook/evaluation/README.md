# 9. 评测与业务验收

## 阶段目标

用代表性证据决定交付是否成立。

## 输入与输出

- 输入：版本化系统、Golden Dataset与业务基线。
- 输出：验收报告、Bad Case与剩余限制。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

分任务、流程、系统、风险、业务五层评估；统计分层结果、成本和人工复核。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

只报告平均准确率会掩盖高风险错误。关键风险失败不能由平均分抵消。

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。继续到 [10. 生产部署与持续运营](../production-delivery/README.md)。
