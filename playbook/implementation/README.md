# 8. 工程实施与系统集成

## 阶段目标

将PoC转成可维护的生产候选。

## 输入与输出

- 输入：通过的假设、接口契约与实施计划。
- 输出：集成版本、回归集、运维草案。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

先跑通端到端链路，再加身份、幂等、超时、Trace、版本与部署脚本。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

模型成功但下游重复写入；按请求ID断言副作用。服务账号最小权限，重试有上限。

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。继续到 [9. 评测与业务验收](../evaluation/README.md)。
