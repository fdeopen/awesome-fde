# 4. 业务对象与本体建模

## 阶段目标

建立跨系统一致的对象、关系和动作语义。

## 输入与输出

- 输入：业务术语、主数据与系统字段。
- 输出：对象字典、关系图、动作权限表。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

以订单、物料和政策为例对齐主键、单位、版本；用异常任务检验关系与规则。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

知识图谱可存储关系，但不能自动决定业务定义。冲突字段保留来源，不静默覆盖。

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。继续到 [5. 数据治理与系统盘点](../data-governance/README.md)。
