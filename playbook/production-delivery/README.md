# 10. 生产部署与持续运营

## 阶段目标

让系统可恢复、可值守、可持续改进。

## 输入与输出

- 输入：四道门证据、发布计划和交接包。
- 输出：发布记录、SLO、运行手册与月度复盘。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

影子运行→有限用户→逐步放量；演练模型故障、索引回滚和人工接管。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

无人负责知识更新会使效果持续衰减。错误承诺或越权触发暂停；指定值班人。
