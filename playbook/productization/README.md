# 12. 资产沉淀与产品化

## 阶段目标

把可重复能力交给明确的产品所有者。

## 输入与输出

- 输入：复盘、变更记录、接口和评测集。
- 输出：资产目录、维护责任与第二次复用报告。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

区分配置与定制；在第二场景验证组件、行业对象、Skill和测试集。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

复制代码造成分叉维护，不能算平台化。明确数据许可、版本兼容与退出方案。

## 完成标准

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。复用后的新问题返回业务发现阶段。
