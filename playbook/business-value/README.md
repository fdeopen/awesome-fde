# 11. ROI评估与项目复盘

## 阶段目标

确认实际采用与可兑现价值。

## 输入与输出

- 输入：观察期数据、成本、对照与任务分布。
- 输出：ROI情景表、归因限制与下一阶段决策。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

区分效率改善与财务收益；纳入人工审核、返工、推理、维护和一次投入。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

节省工时并不自动减少成本；保留实现系数。财务与业务共同复核，报告不确定性。

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。继续到 [12. 资产沉淀与产品化](../productization/README.md)。
