# 7. PoC原型验证

## 阶段目标

证伪最可能阻断项目的假设。

## 输入与输出

- 输入：冻结样本、阈值、预算与章程。
- 输出：PoC报告、逐题结果与继续/停止决定。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

只验证1–3个核心假设；比较现有流程；展示失败样本和长尾结果。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

反复优化同一盲测集导致过拟合。停止条件预先约定，不靠演示挑题过关。

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。继续到 [8. 工程实施与系统集成](../implementation/README.md)。
