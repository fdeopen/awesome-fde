# 5. 数据治理与系统盘点

## 阶段目标

确认数据可用、可追溯且可持续更新。

## 输入与输出

- 输入：系统目录、样本、访问与删除规则。
- 输出：数据资产表、质量报告与接口约定。
- 交接：编制人提交证据版本，业务与技术责任人记录接受、补充或停止决定。

## 工作方法

抽查缺失、重复、过期、权限；实际演练一次增量同步和删除传播。

1. 确认输入的来源、时间与适用范围。
2. 执行上述方法，用稳定ID关联任务、结果与证据。
3. 对关键结论做一次反例检查，再交给下一阶段接收人。

## 常见问题与控制

只有一次性导出不代表持续接入能力。未经授权的数据不进入模型或评测。

输出有明确所有者、版本、证据和下一步；无法支持结论的假设标记为待验证。继续到 [6. 技术方案设计](../solution-design/README.md)。
