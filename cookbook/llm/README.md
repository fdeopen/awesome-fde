# 模型调用与快速原型

## 场景与前提

从一份询价文本提取产品、数量和交期。先使用合成样本，记录当前人工或规则基线。

## 核心设计

结构化Schema、版本化Prompt、无答案处理。

## 操作步骤

1. 准备10条合成询价，先写确定性字段校验。
2. 调用模型后验证输出类型与必填项，失败转待复核。

## 验收与失败路径

缺少交期时返回未知，不自动补日期；记录每次请求的延迟与版本。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
