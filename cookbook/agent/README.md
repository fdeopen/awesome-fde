# 受控工具Agent

## 场景与前提

检索订单状态并生成处理建议。先使用合成样本，记录当前人工或规则基线。

## 核心设计

状态、工具Schema、幂等、人工接管。

## 操作步骤

1. 定义待检索→待复核→完成状态。
2. 只授权查询工具。
3. 设置最大步数与超时。
4. 写动作独立审批。

## 验收与失败路径

无授权调用被拒绝；超时转人工；重复请求不会重复产生副作用。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
