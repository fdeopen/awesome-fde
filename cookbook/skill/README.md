# 可复用Skill

## 场景与前提

将知识清理流程打包为团队能力。先使用合成样本，记录当前人工或规则基线。

## 核心设计

触发、输入输出、步骤、权限、样例。

## 操作步骤

1. 写明适用与排除条件。
2. 把清洗脚本和规则分离。
3. 用成功、缺输入、冲突三类样本验证。

## 验收与失败路径

新同事能复现结果；技能不可静默修改原始文件；失败返回可处理原因。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
