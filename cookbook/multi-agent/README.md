# 多智能体协作

## 场景与前提

分析员提出方案，审阅员检查证据。先使用合成样本，记录当前人工或规则基线。

## 核心设计

职责、消息契约、交接、预算。

## 操作步骤

1. 先实现单工作流基线。
2. 将资料检索与证据审查分成两个角色。
3. 只传摘要、来源ID与问题。
4. 限制协作轮数。

## 验收与失败路径

比较单Agent和多Agent质量/成本；相互同意不等于事实正确，必须回到来源。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
