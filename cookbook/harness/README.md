# 长任务Harness

## 场景与前提

让文档处理任务中断后继续。先使用合成样本，记录当前人工或规则基线。

## 核心设计

持久状态、检查点、预算、工作目录。

## 操作步骤

1. 将任务队列和结果持久化。
2. 每步记录完成证据。
3. 重启时核对产物哈希。
4. 对工具调用设预算与超时。

## 验收与失败路径

中断后不跳步骤、不重复写入；达到预算后返回进度与未决项。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
