# 可回归的工程评测

## 场景与前提

发现版本升级造成的质量回退。先使用合成样本，记录当前人工或规则基线。

## 核心设计

Golden Dataset、切片、断言、Judge校准。

## 操作步骤

1. 冻结开发与盲测集合。
2. 记录逐题版本、成本和判定。
3. 对权限/副作用用代码断言。
4. 抽样复核模型评分。

## 验收与失败路径

统计分母、误差类型和未覆盖范围；盲测失败触发回退或延期。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。

- [行业案例索引](../../cases/catalog.md)：借鉴业务约束，未披露的细节不要补造。

完成后提交设计、版本、输入输出与失败记录四类证据。
