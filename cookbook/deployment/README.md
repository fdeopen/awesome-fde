# 从影子运行到生产

## 场景与前提

把评测通过的版本交给运营。先使用合成样本，记录当前人工或规则基线。

## 核心设计

镜像、配置、灰度、SLO、回滚。

## 操作步骤

1. 记录代码/模型/Prompt/索引版本。
2. 先只读影子运行。
3. 小流量启用。
4. 注入供应商故障和知识过期。

## 验收与失败路径

恢复旧版本后可继续原流程；预算告警能触发；值班人独立完成恢复。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
