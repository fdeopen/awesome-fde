# MCP工具接入

## 场景与前提

提供只读订单查询工具。先使用合成样本，记录当前人工或规则基线。

## 核心设计

协议、身份、资源、工具契约。

## 操作步骤

1. 先用普通函数验证输入输出。
2. 再接入固定版本SDK。
3. 在服务端校验身份与租户。
4. 定义错误码和超时。

## 验收与失败路径

伪造租户与无权限用户均被拒绝；工具描述不能改变权限；日志可追溯请求。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
