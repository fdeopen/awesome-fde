# 权限感知RAG

## 场景与前提

为售后政策生成带证据的答复。先使用合成样本，记录当前人工或规则基线。

## 核心设计

解析、切分、ACL、召回、引用、删除。

## 操作步骤

1. 建立有租户和版本的文档。
2. 先做权限过滤再召回。
3. 要求回答绑定片段ID。
4. 无支持证据时弃答。

## 验收与失败路径

跨租户召回为0；过期条款不被引用；分别记录检索和回答错误。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
