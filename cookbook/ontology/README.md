# 业务本体驱动查询

## 场景与前提

把订单、物料、条款和动作统一起来。先使用合成样本，记录当前人工或规则基线。

## 核心设计

对象ID、关系、规则、来源、有效期。

## 操作步骤

1. 列出业务术语和跨系统主键。
2. 用三条真实或合成任务核查关系。
3. 规则执行与模型解释分离。

## 验收与失败路径

同名异物不合并；单位变化被识别；每次判断可追溯输入对象版本。失败样本进入[Bad Case底稿](../../toolkit/templates/bad-case.md)，修复后重新运行分层评测。
