# 企业 AI 项目 RACI

`A` 为最终负责，`R` 为执行，`C` 为协商，`I` 为知会。同一人可兼任多个角色，但不能删除责任。

| 活动 | 业务负责人 | FDE 负责人 | 平台/产品 | 数据负责人 | 安全法务 | 运营负责人 | 财务 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 问题与基线 | A/R | R | C | C | I | C | C |
| 方案与原型 | C | A/R | R | C | C | C | I |
| 数据授权 | C | C | I | A/R | C | I | I |
| 评估集与阈值 | A | R | C | R | C | C | I |
| 风险接受 | C | R | I | C | A | C | I |
| 上线与回退 | I | R | C | C | C | A/R | I |
| 价值复盘 | A/R | R | C | I | I | C | R |
| 产品化决策 | C | R | A | C | C | C | C |
