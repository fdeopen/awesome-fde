# 运营、价值与产品化

上线后，团队要持续决定：扩大、保持、缩小、降级、产品化还是停止。

## 月度运营复盘

可直接使用 [月度运营复盘模板](../templates/retrospective/monthly-operations-review.md)。

| 领域 | 必须回答的问题 |
| --- | --- |
| 业务 | 用户和任务量如何变化，结果是否优于基线 |
| 质量 | 主要错误、人工修改、新增回归样本是什么 |
| 风险 | 越权、泄露、投诉、近失和例外如何变化 |
| 运营 | SLO、故障、恢复、版本与供应链变化如何 |
| 成本 | 总成本、单位合格结果成本和异常消耗是多少 |
| 采用 | 活跃、留存、放弃、绕过与培训需求如何 |
| 产品 | 哪些需求应配置化、组件化、产品化或拒绝 |
| 决策 | 下一周期扩大、保持、缩小、降级还是停止 |

## 价值证明

严格区分：

- 活动指标：生成次数、活跃用户、任务量
- 效率指标：用时、等待、返工、吞吐
- 经营指标：收入、库存、损失率、留存
- 财务指标：可兑现成本、现金流、毛利、风险资本

“节省时间”只有在用于新增产出、避免招聘、减少加班或改变服务能力时，才可能形成可兑现价值。所有 ROI 都要披露基线、观察期、归因、成本和敏感性。

## 产品化判断

1. 相同问题是否在多个客户或业务单元重复出现？
2. 差异能否通过配置、策略和数据映射吸收，而不是复制代码？
3. 产品团队是否愿意拥有路线图、质量和支持？
4. 复用是否实际缩短周期、提高可靠性或改善单位经济性？

可复用资产包括：Skill、连接器、行业术语/对象模型、评估集、权限模板、运行手册和产品需求。

## 正常结束方式

- **长期运营**：明确所有者、SLO、预算与改进机制。
- **产品化**：进入平台路线图，并度量复用效果。
- **安全停止**：撤销权限、处理数据、归档证据和失败知识。

使用 [项目复盘模板](../templates/retrospective/project-retrospective.md) 保存结论。
