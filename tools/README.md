# 开源工具与产品图谱

工具收录不等于生产推荐。FDE 应先明确业务目标、数据与权限边界、评估方式、团队运维能力和退出成本，再选择产品。

## 通用选型维度

| 维度 | 必问问题 |
| --- | --- |
| 场景 | 它解决的是原型、单应用还是多团队生产平台问题 |
| 控制 | 状态、工具、权限、人工介入和回退是否显式可控 |
| 数据 | 数据位置、保留、删除、训练使用和跨境边界是什么 |
| 评估 | 是否支持数据集、版本、回归、Trace 与业务结果关联 |
| 运维 | 部署、升级、容量、灾备、告警和事故响应由谁负责 |
| 成本 | 许可证、订阅、算力、存储、审核、支持和退出总成本 |
| 生态 | 维护状态、文档、社区、扩展接口和供应商锁定风险如何 |

许可证和商业条款可能变化，请始终以项目仓库与供应商最新说明为准。
