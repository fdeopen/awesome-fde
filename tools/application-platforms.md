# AI 应用平台

适用于快速构建聊天、RAG、Workflow 和 Agent 应用。平台能缩短原型时间，但不会自动补齐业务基线、权限治理、评估集和运营责任。

| 项目 | 适合场景 | 生产评估重点 | 官方入口 |
| --- | --- | --- | --- |
| Dify | 可视化工作流、知识库、模型接入与应用运营 | 多租户、密钥、数据保留、版本和扩展边界 | [GitHub](https://github.com/langgenius/dify) · [文档](https://docs.dify.ai/) |
| FastGPT | 知识库问答、工作流和企业集成 | 文档解析、权限、模型网关和二次开发 | [GitHub](https://github.com/labring/FastGPT) · [文档](https://doc.fastgpt.cn/docs/introduction/) |
| RAGFlow | 复杂文档解析、RAG 与 Agent 工作流 | 解析质量、资源消耗、检索评估和升级 | [GitHub](https://github.com/infiniflow/ragflow) · [文档](https://ragflow.io/docs/dev/) |
| Flowise | 基于节点的 LLM 工作流与 Agent 原型 | 凭据管理、节点可信度、状态和生产运维 | [GitHub](https://github.com/FlowiseAI/Flowise) · [文档](https://docs.flowiseai.com/) |
| n8n | 业务自动化、系统连接与人工审批 | 许可证、凭据、执行权限、幂等和失败补偿 | [GitHub](https://github.com/n8n-io/n8n) · [文档](https://docs.n8n.io/) |

`核验：2026-09-07`。许可证请查看各项目当前 `LICENSE`，其中部分项目属于 source-available，而非 OSI 定义的开源软件。
