# 交付检查单

在进入下一阶段前，由接收责任人核对证据版本；复用[上线四道门](../../templates/acceptance/launch-gate.md)。

| 时点 | 要核对的证据 | 失败后动作 |
| --- | --- | --- |
| PoC开始 | 明确用户、基线、数据授权、盲测集与阈值 | 先补数据或缩小范围 |
| 工程接入 | 输入输出Schema、身份透传、幂等、超时与回退 | 保持沙箱只读 |
| 业务验收 | 五层评测、分层结果与人工复核记录 | 分类修复并回归 |
| 有限上线 | 灰度比例、值班、预算、停止开关与恢复演练 | 延期发布 |
| 运维接手 | 独立恢复演练、知识更新与供应商退出路径 | 原团队继续承担值班 |
| 复用推广 | 第二个场景的独立结果与差异成本 | 保留定制项，暂不产品化 |
