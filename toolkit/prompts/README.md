# 交付工作提示词

使用合成或已授权片段；用需求ID和证据编号替代客户敏感信息。提示词是协作草稿，结论由责任人复核。

## 访谈归纳

```text
将访谈记录按“原话证据、观察事实、待验证假设、分歧、下一步”归类。
每条结论绑定记录行号，不补造基线数字。
输出用户、触发、输入、步骤、异常、输出和责任人；缺失字段写“未提供”。
最后列出会改变立项决定的三个未解问题。
```

## 架构审阅

```text
根据需求ID、数据流和工具清单审查方案。
逐项指出身份在哪里验证、数据在哪里过滤、动作如何幂等、失败如何接管。
每个问题写出复现条件、业务影响和最小验证办法。
不要假定框架默认提供业务授权；引用具体配置或标记待证实。
```

## 价值复盘

```text
根据基线、观察期、采用数据与成本表，分开列活动、效率、经营和财务结果。
只对有证据的归因计算收益；缺失的实现系数保持未知。
输出继续、缩小、停止或产品化的建议，并列明使建议改变的条件。
```
