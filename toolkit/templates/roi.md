# ROI测算模板

对应交付阶段：11，见 [Playbook](../../playbook/README.md)。

## 使用说明

公式见计算器；分别列工时改善与可兑现收益，做低/中/高敏感性分析。

复制下表填写“项目填写”列。项目ID、版本、日期、编制人、复核人和证据地址应一并记录。示例为合成教学数据，阈值与金额均不代表真实客户结果。

## 工作底稿

| 字段 | 项目填写 | 模拟填写示例 |
| --- | --- | --- |
| 基线工时 |  | 模拟1000任务/月×10分钟 |
| 改进工时 |  | 每任务节省4分钟 |
| 人工单位成本 |  | 模拟60元/小时 |
| 实现系数 |  | 0.5，节省时间仅部分变现 |
| 每月新增成本 |  | 模拟1000元 |
| 一次投入 |  | 模拟12000元 |
| 一年净ROI |  | ((2000-1000)×12-12000)/12000=0% |
