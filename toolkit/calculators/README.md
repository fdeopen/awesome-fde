# ROI离线计算器

```bash
python3 toolkit/calculators/roi.py --tasks 1000 --saved-minutes 4 --hourly-cost 60 --realization 0.5 --monthly-cost 1000 --upfront 12000 --months 12
```

默认参数全部为模拟数据，输出0.25、指定值、0.75三种实现系数的情景。必须用同一币种和观察期。

- 节省工时/月 = 任务量 × 单任务节省分钟 ÷ 60。
- 可兑现收益/月 = 节省工时 × 小时成本 × 实现系数。
- 净收益/月 = 可兑现收益 − 新增运营成本（应含审核、返工和维护）。
- 观察期净价值 = 净收益/月 × 月数 − 一次投入。
- 一次投入ROI = 观察期净价值 ÷ 一次投入；一次投入为0时输出null。
- 简单回收月数 = 一次投入 ÷ 净收益/月；净收益非正时输出null。

默认中位情景月净收益1000元、12个月净价值0元、一次投入ROI为0。该口径不同于“总成本ROI”，也不考虑贴现、税费或增长收益；作为[ROI底稿](../templates/roi.md)的一个估算工具。
