# FDE Roadmap · 系统化学习路线

先选与你现有经验相符的路线，再按交付产物评估进展。每条路线的时间安排由任务规模决定，不以学习天数承诺能力等级。

| 路线 | 起点 | 最终产物 |
| --- | --- | --- |
| [入门](beginner.md) | 初学者、业务与转型人员 | 可运行小应用和基础评测 |
| [工程进阶](intermediate.md) | 软件、AI工程师与架构师 | 可恢复、可观测、带权限的系统 |
| [交付专家](advanced.md) | 资深FDE、咨询与企业负责人 | 业务验收、ROI与可复用资产 |
