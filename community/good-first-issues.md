# 适合首次参与的贡献

以下是可认领的任务建议，不是已经创建的GitHub Issue。

| 任务 | 完成证据 | 预计范围 |
| --- | --- | --- |
| 修复一个外链 | 原地址、规范新地址、核验日期 | 单条资源 |
| 复现离线例子 | 环境版本、命令、结果与一个失败样本 | 一个示例 |
| 完善一份模板 | 合成填写示例、字段含义与验收方法 | 一份模板 |
| 复核案例来源 | 原文、披露日期、缺失字段与类型 | 一篇索引 |
| 章节学习反馈 | 对应章节、练习卡点与可验证建议 | 一章导航 |
| 英文校对 | 中英含义对照与修订理由 | 一个段落 |

提交[Issue](https://github.com/fdeopen/awesome-fde/issues/new/choose)说明计划，或直接按[贡献指南](../CONTRIBUTING.md)提交小范围PR。维护者可对确认适合入门的Issue设置 `good first issue` 标签。
