Awesome-FDE是统一开放知识与图书配套入口；其他站点按产业、技术与人才定位连接实践者。

微信公众号：**FDE前线**。图书提供系统化知识，仓库提供持续更新的实践与协作资料。

## 参与方式

- [贡献指南](../CONTRIBUTING.md)：选题、证据、许可与评审。
- [Issue表单](https://github.com/fdeopen/awesome-fde/issues/new/choose)：勘误、资料、案例、项目、模板、工程问题、社区建议。
- [首次贡献](good-first-issues.md)：可从一次核验或练习复现开始。
- [贡献者](contributors.md)：由Git历史生成公开名称列表。
- [活动](events.md)：只记录已确认信息。
- [项目路线图](../ROADMAP.md)：当前维护优先级。

每项内容指定维护责任；来源失效或授权变化时先保留修订记录，再修复或下架受影响内容。
