# FDE 作品集指南

好的 FDE 作品集展示决策链和结果边界，而不只是最终界面。

## 每个项目应展示

1. 原流程、用户、系统、基线和业务负责人
2. 为什么选择这个问题，以及明确不做什么
3. 关键假设如何被验证、推翻或调整
4. 架构、数据、权限、工具与人工接管
5. 评估集、阈值、典型错误和变更复测
6. 上线范围、SLO、成本、采用和业务结果
7. 归因限制、事故/失败复盘和停止条件
8. 可复用组件、Skill、模板和产品反馈

## 建议结构

```text
一句话场景
→ 现状流程与基线
→ 决策与架构权衡
→ 可运行系统与评估证据
→ 上线、风险和运营
→ 结果、局限与复用
```

## 保护客户信息

- 使用合成或经授权脱敏数据。
- 用角色、行业和量级区间替代可识别名称。
- 不展示内部域名、账号、密钥、合同、真实日志或截图。
- 无法公开细节时，重点展示方法、责任、权衡和验证方式。

## 最低毕业作品

- 一个可运行、可评估、有 Trace 和回退的小系统
- 一份真实流程与机会卡
- 一套版本化评估集和失败样本
- 一份上线门禁或安全停止结论
- 一个被复用的模板、组件或 Skill
