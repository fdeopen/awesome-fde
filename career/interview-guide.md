# FDE 面试指南

FDE 面试应使用工作样本和行为证据，避免只考术语或算法题。

## 建议流程

| 环节 | 目的 | 强证据 |
| --- | --- | --- |
| 经历深挖 | 验证端到端责任 | 能说明用户、故障、采用、结果和局限 |
| 业务发现 | 观察问题定义 | 先问流程、基线、异常、责任和停止条件 |
| 系统设计/现场编码 | 验证工程深度 | 权限、日志、测试、回退和成本一起考虑 |
| 评估设计 | 验证 AI 可靠性 | 设计真实任务、阈值、回归和风险样本 |
| 复盘沟通 | 验证客户共创 | 能表达坏消息、权衡、边界和下一步 |
| 产品化判断 | 验证复用意识 | 区分配置、组件、平台与复制代码 |

## 示例题

> 客户希望用 Agent 自动处理供应商异常。

优秀候选人不会立刻选择模型，而会先确认：异常类型、当前流程、用户、授权边界、错误成本、系统接口、历史样本、业务基线、人工接管和停止条件。

## 候选人准备

- 准备两个项目：一个成功、一个失败或停止。
- 说明你亲自承担的决策与工程工作，不把团队成果全部归己。
- 展示评估、Trace、事故、回退、成本和采用证据。
- 说明哪些结论是事实、推断或客户/供应商自述。
- 准备讨论一个项目如何被第二次复用，以及复用是否真正降低成本。
