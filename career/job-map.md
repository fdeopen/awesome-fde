# FDE 岗位地图

中国市场的岗位名称尚未统一，FDE 型职责可能分布在多个职位家族中。

## 常见相邻岗位

| 岗位家族 | 常见优势 | 需要补齐 |
| --- | --- | --- |
| AI 应用/全栈工程师 | 构建与集成 | 业务发现、客户决策、采用与产品化 |
| 大模型交付/实施工程师 | 上线与项目执行 | 工程深度、评估和平台反馈 |
| 解决方案架构师/售前 | 发现、方案和客户沟通 | 生产所有权、维护与业务结果 |
| 数据/算法工程师 | 模型、数据和指标 | 真实流程、系统集成和用户采用 |
| 产品经理/客户成功 | 用户、价值和推广 | 直接工程实现、可靠性和治理 |
| 咨询顾问/行业专家 | 业务与组织判断 | 可运行系统、评估和生产运营 |
| 平台/SRE/MLOps | 可靠性、成本和治理 | 客户场景、业务流程和产品反馈 |

## 阅读 JD 的四问

1. 是否对生产上线与业务结果负责？
2. 是否直接构建、测试和维护可运行系统？
3. 是否持续与真实用户、业务和技术团队共创？
4. 是否把重复问题反馈并推动产品化？

四项都强，接近核心 FDE；两到三项强，属于 FDE 相邻岗位；只因标题含“部署”“解决方案”或“AI”不能判断。

岗位、薪资和公司信息变化快。贡献相关数据时必须记录原始职位页、访问日期、地区、币种、样本和去重口径。
