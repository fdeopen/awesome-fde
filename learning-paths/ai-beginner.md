# AI 应用入门路线

适合产品经理、业务人员、传统软件工程师，以及第一次系统学习大模型应用的人。

## 毕业目标

完成一个解决真实小问题的 AI 应用，并能解释它的用户、输入、输出、评估方式、成本和风险边界。

## 学习顺序

| 阶段 | 学习重点 | 实践产物 |
| --- | --- | --- |
| 1. 基础概念 | Token、上下文、Embedding、推理、幻觉 | 一页概念图与模型能力边界清单 |
| 2. Prompt 与结构化输出 | 指令、示例、JSON Schema、错误处理 | 10 条真实样本与稳定输出格式 |
| 3. 最小应用 | API、低代码工作流或简单前后端 | 一个端到端可运行应用 |
| 4. 基础评估 | 正确性、完整性、延迟、成本、风险 | 评估表、失败样本与改进记录 |
| 5. 用户验证 | 观察真实用户完成任务 | 反馈记录与下一版范围 |

## 推荐练习

- 把一份固定格式文档抽取成结构化 JSON
- 为一个内部 FAQ 场景建立带引用的检索问答
- 为客服、销售或行政流程生成草稿，但保留人工确认

## 毕业检查

- [ ] 有明确用户、触发条件和当前流程
- [ ] 使用真实或经授权的脱敏样本验证
- [ ] 输出格式可被下游系统消费
- [ ] 记录典型错误、延迟和单次任务成本
- [ ] 对高风险输出设置人工复核
- [ ] 能说明什么情况应该停止使用 AI
