# AI Infra 与生产化路线

适合平台工程师、架构师、SRE、MLOps 工程师，以及负责企业级模型服务与治理底座的团队。

## 毕业目标

设计并验证一套支持多模型、多应用和多团队的生产基线，覆盖服务、网关、权限、评估、可观测、成本、变更和灾备。

## 学习顺序

| 阶段 | 学习重点 | 实践产物 |
| --- | --- | --- |
| 1. 推理基础 | GPU、显存、批处理、并发、吞吐、延迟 | 容量与压测报告 |
| 2. 模型服务 | 版本、量化、缓存、路由、弹性 | 服务拓扑与 SLO |
| 3. AI Gateway | 认证、配额、路由、审计、预算 | 网关策略与租户模型 |
| 4. 数据与知识 | ETL、向量库、权限过滤、保留与删除 | 数据流与分级清单 |
| 5. 评估与观测 | Trace、质量门禁、回归、漂移、成本 | 评估流水线与仪表盘 |
| 6. 治理与运维 | 变更分级、供应链、事故、回退、退出 | 运行手册与演练记录 |

## 毕业检查

- [ ] 有性能、容量、可用性和成本基线
- [ ] 模型、Prompt、知识源、连接器与策略均可版本化
- [ ] 身份、租户、数据、工具权限和审计链路清晰
- [ ] 变更按低、中、高风险分级并匹配复测要求
- [ ] 模型或供应商不可用时有降级与业务连续性方案
- [ ] 日志遵循数据最小化和分层保留原则
- [ ] 能计算每个请求、完成任务和合格业务结果的成本
