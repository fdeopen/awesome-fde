# 企业 AI FDE 路线

适合解决方案架构师、实施顾问、产品经理、全栈工程师、咨询顾问和企业 AI 项目负责人。

## 毕业目标

围绕一个真实工作流，完成从客户发现、方案设计、PoC、生产上线、采用、价值验证到产品化复盘的完整方案包。

## 学习顺序

| 阶段 | 要回答的问题 | 核心产物 |
| --- | --- | --- |
| 1. 角色与边界 | 谁对业务、技术、数据、风险和运营负责 | 利益相关者图、RACI |
| 2. 业务发现 | 哪个高频、高价值、可测量问题值得做 | 现状流程、基线、机会卡 |
| 3. 价值与可行性 | 数据、权限、集成、风险和经济性是否成立 | 就绪度评分、风险地图 |
| 4. PoC | 最关键的不确定性是什么 | PoC 章程、真实任务集、退出结论 |
| 5. 生产化 | 如何让系统安全、稳定、可运营 | 四道门、SLO、回退、交接包 |
| 6. 采用与价值 | 用户是否持续使用，结果能否归因 | 采用指标、单位结果成本、价值复盘 |
| 7. 产品化 | 哪些经验可以跨项目复用 | Skill、连接器、模板、评估资产 |

## 最终方案包

- 业务场景、用户角色、现状流程与基线
- 机会卡、价值假设、排除项和停止条件
- RAG/Workflow/Agent 架构选择与数据流
- 数据目录、权限、工具、系统接口和风险登记
- PoC 章程、版本化评估集、错误分类和结论
- 上线四道门、SLO、监控、回退、人工接管和培训
- 采用、质量、成本、ROI 及归因限制
- 项目复盘、产品反馈与可复用资产

## 毕业检查

- [ ] 能把模糊需求翻译成可验证的业务命题
- [ ] 能直接参与原型、集成、评估和生产问题处理
- [ ] 能在坏消息出现时尽早同步并调整范围
- [ ] 能区分活动指标、效率指标、经营指标和财务结果
- [ ] 能做出继续、调整、降级、产品化或停止的决策
- [ ] 至少沉淀一个跨项目可复用资产
